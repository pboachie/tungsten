SDK guides

Each SDK target is a typed client plus a README that tungsten generates next to it. The SDKs provide a shared safety envelope: arguments are validated before transport, failures carry diagnostic information, and destructive operations support previews and confirmation. Each language exposes its own result or error shape; Go, for example, returns typed errors. See runtime distribution before using an install snippet: generated package names are examples, and source availability does not establish registry publication.

For the released 0.1.2 compiler, the runtime distribution guide identifies verified 0.1.2 npm, PyPI, Maven Central, NuGet and RubyGems packages. Select those versions explicitly when generating a stable project. Rust uses the matching source checkout until its required crates are available. Kotlin, F# and Dart require the unreleased 0.1.3 compiler and their matching candidate runtime source; those three targets are not present in the released 0.1.2 compiler. The 0.1.3 compiler also needs matching candidate runtime source for its newer capabilities. The generated examples below illustrate their recorded source configuration, not proof that an example package or candidate runtime is published.
