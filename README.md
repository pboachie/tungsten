# tungsten

High-performance, agent-native SDK generator and MCP compiler written in Rust. Compiles OpenAPI specifications into hardened client libraries, sandboxed MCP servers, and self-healing tools for AI agents.

**Status:** early development. The compiler frontend and intermediate representation are being built; no emitters exist yet.

```sh
cargo build --release
./target/release/tungsten check path/to/openapi.json
./target/release/tungsten ir dump path/to/tungsten.yml
```

## Contributing

This repository contains source code only. The test suite, conformance corpus and design documents are maintained in a separate repository by the maintainers, who run them against every pull request. Open an issue to discuss a change before sending a large patch.
