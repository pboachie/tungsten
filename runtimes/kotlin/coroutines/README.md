# tungsten-runtime-kotlin-coroutines (Kotlin)

The opt-in suspend and Flow layer for SDKs generated by
[Tungsten](https://github.com/pboachie/tungsten) with the Kotlin target option
`coroutines: true`. It is a separate artifact so that
`tungsten-runtime-kotlin` keeps depending only on the Java runtime and
kotlin-stdlib; this one adds `kotlinx-coroutines-core` (pinned to 1.10.2).

```
io.github.pboachie.tungsten:tungsten-runtime-kotlin-coroutines
```

- `suspending { call }` runs one blocking runtime call as a cancellable suspend
  call on `Dispatchers.IO` (or the dispatcher you pass) and returns its
  `Result`. Cancelling the coroutine interrupts the call; a mutation cancelled
  after it was sent has an unknown outcome: reuse its idempotency key.
- `pagesFlow { pages }` and `eventsFlow { stream }` are cold `Flow`s of the
  runtime's page and event results, pull based with no buffer of their own.

See the Kotlin runtime README for the shared contract and for building from
source.
