# tungsten runtime (Go)

Runtime support for SDKs generated by [Tungsten](https://github.com/pboachie/tungsten).

## Install from source

Use Go 1.22 or newer. Until the runtime's module version is published, use a
local replacement in the consuming module (adjust the checkout path):

```sh
go mod edit -replace github.com/pboachie/tungsten/runtimes/go=../tungsten/runtimes/go
go mod tidy
```

Generated Go clients import `github.com/pboachie/tungsten/runtimes/go`.
The runtime uses the standard library and accepts a caller-supplied HTTP client.

## Shared contract

Generated clients use the runtime for request validation, authentication,
idempotency keys, confirmation previews, bounded retries, verification,
pagination, macros and server-sent events where the input API declares them.
Calls return a typed result or a diagnostic envelope describing recovery;
unknown outcomes never justify blindly repeating a mutation. The API remains
responsible for authorization and server-side idempotency.

## Limits

Calls are synchronous and cancellation uses `context.Context`.
Memory stores are process-local; use the file idempotency store or an
application-owned store when key reuse must survive restarts.

No runtime ships a file-backed OAuth token store. Provide an application-owned
token-store implementation when tokens must survive process restarts; protect
stored credentials and avoid logging them. Registry publication and package
availability are separate from building this source checkout.
